# Preset Seed Lab

Lightroom XMP 프리셋을 만들고 조합하는 Windows 데스크톱 앱입니다. 기존 프리셋 변주, 항목별·랜덤 믹스매치, 사진에서 스타일 추정을 지원합니다.

## 빠른 시작

1. 프로젝트 폴더의 **PresetSeedLab.exe**를 실행합니다. EXE와 `app.ps1`, `ui/`, `core/`, `assets/`를 함께 보관하세요.
2. 사이드바의 **프로젝트 → 폴더 선택**으로 작업을 저장할 폴더를 정합니다.
3. 아래에서 원하는 생성 방식을 선택하고 XMP 또는 사진을 추가합니다. 파일이나 폴더를 입력 목록에 끌어다 놓아도 됩니다.
4. 생성 개수와 저장 폴더를 확인한 뒤 생성합니다. 비용 없이 시작하려면 프리셋 생성·믹스매치의 **AI 사용**을 끄세요.
5. 결과 XMP를 Lightroom으로 가져와 사진에 적용합니다.

Windows 10/11 x64의 Windows PowerShell 5.1, WPF, Windows Script Host를 사용합니다. 앱 실행에는 Node.js·Python·관리자 권한이 필요하지 않습니다. Lightroom이나 Adobe API 연결 없이 XMP를 생성합니다.

## 생성 방식

| 화면 | 입력 | 결과 개수 | AI |
| --- | --- | --- | --- |
| **프리셋 생성** | 내 XMP 프리셋 1개 이상 | 1~120개 | 선택 |
| **프리셋 믹스매치** | XMP 프리셋 2~12개 | 1~24개 | 선택, 기본 꺼짐 |
| **레퍼런스로 만들기** | JPG·PNG 사진 1~24장 | 1~120개 | 필수 |

### 프리셋 생성

1. **XMP 추가** 또는 **폴더 추가**로 씨드(새 프리셋의 바탕)를 등록하고 사용할 항목을 체크합니다.
2. 6개 분류의 분위기 키워드 60개 중 원하는 것을 고릅니다. 키워드는 후보별로 나눠 적용하며, 선택하지 않으면 자연스럽게 변주합니다.
3. **씨드 충실도**와 **변주 폭**을 정합니다. 기본값은 충실도 85, 변주 폭 70, 후보 24개입니다.
4. 필요하면 인물·배경 마스크를 추가하고 **프리셋 생성**을 누릅니다.

충실도가 높을수록 원래 색감을 유지합니다. 100에서는 색감과 화이트밸런스를 고정해도 밝기·질감은 변할 수 있습니다. 변주 폭 0은 씨드의 보정값을 유지합니다. 비슷한 후보는 제외하므로 실제 생성 수가 요청보다 적을 수 있습니다.

**AI 보정 제안**을 켜면 씨드·키워드·메모를 참고해 변주 방향을 제안합니다. 선택 항목인 **프리셋을 적용할 사진**에는 보정하려는 사진을 넣으세요. AI가 밝기와 조명을 참고하며, 사진 없이도 생성할 수 있습니다.

### 프리셋 믹스매치

1. XMP 2~12개를 추가하거나 **씨드에서 가져오기**를 누릅니다.
2. 슬라이더로 비율을 정합니다. 10과 30은 25%/75%로 환산하며, **0인 프리셋은 제외**합니다.
3. **톤·색감·질감·커브**마다 혼합 방식을 고릅니다.
4. 기준 프리셋과 생성 개수를 정한 뒤 **믹스매치 생성**을 누릅니다.

| 항목별 선택 | 동작 |
| --- | --- |
| **비율대로 섞기** | 슬라이더의 상대 비율로 혼합 |
| **랜덤으로 섞기** | 후보마다 출처와 비율을 무작위로 선택 |
| **기준 프리셋 유지** | 해당 항목의 기준값 유지 |
| 특정 프리셋 이름 | 해당 프리셋의 값을 가져오기 |

**모두 랜덤으로**는 네 항목과 기준 프리셋을 한 번에 랜덤으로 설정합니다. 랜덤 항목은 비율이 0보다 큰 프리셋 중에서 고르며, 슬라이더 비율의 크기는 추첨 확률에 영향을 주지 않습니다. **조합 탐색 폭**이 0이면 항목마다 한 프리셋을 고르고, 높일수록 여러 프리셋을 섞는 조합이 늘어납니다. 첫 후보부터 랜덤이며, 생성할 때마다 새 랜덤 시드를 사용합니다.

기준 프리셋은 화이트밸런스·프로필·LUT·마스크·크롭 등 혼합하지 않는 설정의 출처입니다. **랜덤 · 후보마다 선택**도 사용할 수 있고, 실제 기준과 항목별 비율은 결과에 표시됩니다.

**AI 조합 추천**을 켜면 혼합 비율을 다듬습니다. 랜덤 항목은 먼저 만든 조합의 보정값·커브를 보고 추천 비율을 최대 20% 반영하며, 비율대로 섞기는 최대 50% 반영합니다. 직접 지정한 항목과 후보별 기준은 유지합니다. 현상 버전이 다르거나 컬러·흑백 방식이 다른 프리셋은 함께 섞을 수 없습니다.

### 레퍼런스로 만들기

1. 참고할 JPG·PNG 1~24장을 추가합니다.
2. **사진들의 공통 스타일** 또는 **사진마다 다른 스타일**을 고릅니다. 사진별 방식에서는 총 생성 개수가 사진 수 이상이어야 합니다.
3. API 키와 이미지 입력·구조화 출력을 지원하는 모델을 지정합니다.
4. 필요하면 **적용할 원본 사진**에 보정 전 JPG·PNG를 넣습니다. RAW 작업에는 보정 전 미리보기 JPG를 사용하세요.
5. 인물·배경 보정, 키워드와 생성 개수를 정하고 생성합니다. 각 스타일의 첫 후보는 추정 기본값이며, 나머지는 로컬 변주입니다.

**보정 자료 검색**은 기본으로 켜져 있으며, 사진 분석에 맞는 보정 자료와 출처를 검색합니다. API 요청과 검색 비용이 추가될 수 있습니다. 검색에는 스타일 설명을 전달합니다.

사진에서 색감·톤·질감을 추정하므로 조명·소재·메이크업의 영향도 포함될 수 있습니다. 원래 프리셋이나 정확한 보정 수치를 복원하지 않으며, 결과의 확신도는 측정된 일치율이 아닙니다.

## 인물·배경 마스크

**인물·피사체 추가**와 **배경 추가**는 템플릿 없이 사용할 수 있고, 마스크 추가 자체에는 OpenAI 호출이나 사진 전송이 없습니다. 레퍼런스 화면에서는 **자동 선택 · 템플릿 없이**가 기본입니다.

- **인물·피사체**는 Lightroom의 Select Subject를 사용합니다. 사진에 따라 사물도 선택될 수 있습니다.
- **배경**은 피사체 선택 영역의 반전입니다. 풍경 요소를 고르는 Select Landscape와는 다릅니다.
- 실제 영역은 **사진에 프리셋을 적용할 때 Lightroom이 계산**합니다. XMP 가져오기는 프리셋을 등록하는 단계이며, 적용 후 필요하면 마스크를 업데이트하세요.

### 기존 마스크 사용하기

**프리셋 생성 → 다른 XMP의 마스크 가져오기**에서는 마스크를 포함해 저장한 XMP를 선택합니다. 생성 결과에서 이 파일의 마스크가 씨드의 기존 마스크를 대체하고, 전체 보정은 씨드를 기준으로 합니다. 체크한 자동 마스크는 함께 추가됩니다.

**기존 인물·배경 마스크의 보정값도 변경**을 켜면 씨드 또는 가져온 XMP의 인물·배경 마스크에 저장된 노출·대비·부분 대비·채도를 바꿉니다. 이름에 인물·피사체·배경 또는 Subject·Person·People·Portrait·Background가 포함되거나 이름이 BG인 마스크를 인식합니다. 선택 영역은 유지합니다.

레퍼런스에서 직접 만든 마스크를 쓰려면 Lightroom에서 피사체·배경 마스크를 포함한 프리셋을 XMP로 내보낸 뒤 **직접 만든 템플릿 사용 → 템플릿 선택**으로 엽니다. 인물과 배경에는 서로 다른 자동 선택 그룹을 지정합니다. 선택한 그룹의 영역을 가져오고 영역별 보정값은 새로 추정합니다. 두 보정 체크를 모두 끄면 전체 보정만 만듭니다.

## 프로젝트와 결과

프로젝트 폴더를 선택하면 입력 파일을 `seeds/`, `references/`, `photos/`, `masks/`, `mix/`에 복사하고 목록·옵션·메모·마지막 결과를 `seedlab-project.json`에 자동 저장합니다. 경로는 프로젝트 기준 상대 경로이며, 다음 실행 때 마지막 프로젝트와 결과를 복원합니다. 목록에서 제외해도 복사된 파일은 남습니다. 프로젝트를 지정해야 입력 목록이 저장됩니다.

생성할 때마다 저장 위치 아래에 새 결과 폴더를 만듭니다. 기본 위치는 `<프로젝트>/outputs`입니다.

| 파일 | 내용 |
| --- | --- |
| `*.xmp` | Lightroom으로 가져올 프리셋 |
| `manifest.json` | 기준·키워드·비율·변경값·랜덤 시드·사용량·저장 상태 |
| `analysis.txt` | 레퍼런스 분석·검색 출처·수치 보정 내역 |

**생성 결과**에서 후보별 변경값과 비율을 확인하고, 행을 더블클릭하면 탐색기에서 XMP를 선택합니다. 오류나 중지 후에도 저장된 부분 결과와 확인된 사용량을 남깁니다. 원본 XMP와 사진은 수정하지 않습니다.

## AI·사용량·개인정보

- 생성 화면들은 같은 API 키를 공유합니다. 키는 기본적으로 메모리에만 두며, **이 PC에 API 키 저장**을 켜면 현재 Windows 계정으로 암호화해 저장합니다. 끄면 저장된 키를 삭제합니다.
- 씨드 생성에서 선택한 사진, 레퍼런스와 원본 사진은 AI 처리 시 긴 변 1024px 이하의 사본을 전송합니다. 믹스매치는 보정 수치를 전송합니다.
- API 키는 프로젝트·결과·사용량 기록에 저장하지 않습니다. 원본 사진은 결과·사용량 기록에 포함하지 않으며, 프로젝트를 사용하면 작업 폴더에 복사됩니다.
- 대시보드는 이 앱의 호출·토큰·검색·생성 작업과 예상 비용을 보여 주고 CSV로 내보냅니다. 다른 앱의 API 사용량은 포함하지 않습니다. 비용은 참고값이며 실제 청구 금액은 제공자에서 확인하세요.
- 실패한 AI 요청을 자동 재시도하지 않습니다. 응답을 받아 확인한 사용량은 후속 처리 실패 후에도 유지하고, 응답을 받지 못한 호출은 미확인으로 표시합니다.

단축키: **Ctrl+Enter** 생성 · **Ctrl+1~5** 화면 이동 · **Ctrl+O** 파일 추가 · **F5** 대시보드 새로고침.

## 개발과 검증

개발 구조·테스트·빌드 명령은 [개발 안내](docs/DEVELOPMENT.md), 세부 검증 기록은 [validation.json](docs/validation.json)에 있습니다.

현재 로직 테스트 78개와 Windows PowerShell/WPF/WSH 통합·실제 EXE 조작 검사를 통과했습니다. AI 경로는 모의 응답으로 검사했으며 실제 API 호출과 Lightroom 가져오기·마스크 계산·보정 품질은 별도 확인이 필요합니다. 사용자 지정 프로필/LUT가 필요한 프리셋은 Lightroom에도 해당 리소스가 있어야 합니다.
